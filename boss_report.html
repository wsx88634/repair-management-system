📌 執行摘要 (Executive Summary)

針對本公司專營蒸烤箱、咖啡機等餐飲設備維修「時效緊迫」、「等零件/另約營業空檔」之現場實務特性，我們完成了全新的數位叫修輔助管理平台。本系統徹底解決過去 Google 多帳號切換導致系統當機與權限混淆的營運痛點，全面優化派單流暢度，降低掉單風險並建立維修大數據資產。

🎯 現行營運痛點與數位化對策

痛點一

Google 多帳號 Session 權限衝突導致系統當機

現狀問題：內勤與工程師電腦常同時登入個人與公司 Google 帳號，導致舊 Apps Script 出現 403 權限錯誤或跳出 HTML 當機選單。
✨ 數位對策：採用獨立免帳號混淆 Web API 技術，100% 雲端穩定連線，告別當機與掉單風險。

痛點二

門市急修與零件等待進度混亂、電話重複溝通

現狀問題：連鎖客戶（如全家門市）急修案件多，工程師現場常因等待零件或需避開門市用餐高峰而延後，內勤無法即時掌握狀態。
✨ 數位對策：增設獨立「待指派區」、「報價進度專區」與「另約時間」看板，狀態透明一目瞭然。

痛點三

缺乏維修時效監控與歷史維修履歷資產

現狀問題：無法精準統計合約 SLA 達成率，歷史叫修資料散落於通訊軟體或紙本。
✨ 數位對策：內建 SLA 時效自動紅字預警、430+ 筆歷史叫修履歷模糊搜尋，並支援 CSV 數據分析匯出。

🚀 系統 5 大核心營運效益

01. 5 大動態流程看板

未執行 ➔ 另約時間 ➔ 報價 ➔ 完修 ➔ 取消。專為門市營業空檔與等待原廠零件特性設計。

02. 獨立報價進度專區

精準追蹤「未報價/已報價/同意報價」，提升備料效率與客戶同意率，保障維修毛利。

03. SLA 時效逾期預警

設定合約要求天數，超時案件卡片自動跳動紅字警報，大幅降低連鎖客戶抱怨率。

04. 現場圖片與對話整合

可夾帶故障照片與報價單，並自動解析門市電話、地址、保固狀態與故障主因。

🛡️ 資訊安全與管理總結

本系統所有維修單據皆安全儲存於公司專屬 Google 雲端資料庫，資料產權完全歸公司所有。管理者關鍵設定（後端 API 與全量 CSV 匯出）皆設有權限防護鎖，防止非授權人員誤觸或洩漏數據。
