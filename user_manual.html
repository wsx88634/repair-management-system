🛠️ 叫修輔助管理系統 - 團隊全功能操作說明書

適用對象：內勤客服派單人員、現場維修工程師、後勤業務主管

SOP 標準維修流程

1. 頂部工具列與雲端狀態

• 連線狀態標籤：顯示 🟢 GAS API 已連線 表示與雲端資料庫同步中；如顯示 🟡 本地體驗模式 表示離線本機儲存。
• 後端 API 設定：點擊後需輸入管理者防護密碼以維護連線網址。
• 一鍵封存結案：自動掃描看板上所有已「完修」或「取消叫修」的單據，批次歸檔至歷史庫。
• 重新整理：手動與雲端連線拉取最新派單與工程師動態。

2. 新增派單作業 (內勤客服流程)

Step 1: 填寫基本資料

設定「報修日期」、客戶門市名稱（如：全家-葵爾特店）與設備機型（如：Rational 蒸烤箱、Dalla Corte 咖啡機）。

Step 2: 選擇工程師與時效

可指定負責工程師；若尚未確定則選「未指派」（進入待指派區），並設定 SLA 要求時效天數。

Step 3: 輸入備註細節與建立

填入詳細聯絡人、電話、門市地址與故障狀況，點擊 `＋ 建立派單` 即可發送至看板。

3. 待指派區 & 報價追蹤專區

📥 待指派放置區：未指定工程師的案件會暫存於此，可以隨時以滑鼠拖拉卡片至下方工程師欄位中完成派單。
📊 報價進度追蹤區：當單據狀態轉為「報價」時會自動進入此專區，可一鍵切換狀態： 未報價 ➔ 已報價 ➔ 同意報價。

4. 工程師主看板 5 大維修階段說明

維修階段 適用現場狀況與使用時機
1. 未執行 剛剛指派給工程師、尚未出勤排修的初始案件。
2. 未完成 / 另約時間 門市用餐高峰無法維修、需另約空檔，或等待原廠零件到貨時切換。
3. 報價 需評估高單價零件（如加熱基板、泵頭）與工資，等待客戶回覆同意。
4. 完修 現場維修測試正常、完工交機。
5. 取消叫修 客戶門市自行排除故障或重複叫修撤單。

5. 單據詳細編輯與現場圖片上傳

• 編輯資訊：點擊看板卡片可開啟彈出視窗，更新客戶、機型、完成日期與備註細節。
• 上傳現場照片：點擊 `☁️ 上傳圖片` 可上傳門市故障照片或報價單（因雲端容量限制，每單限上傳 1 張照片，系統會自動壓縮解像度）。
• 封存與刪除：完修單據可點擊 `📦 封存單據` 隱藏或點擊 `🗑️ 完全刪除` 永久移除。

📊 歷史複查、報表匯出與螢幕擷取

🔍 歷史複查
輸入門市關鍵字或機型，可檢視累積叫修次數與完修達成率。
📥 匯出報表
輸入授權密碼後，可依日期區間匯出 CSV 報表檔。
📷 擷取看板
點擊相機圖示，可將看板轉為高畫質 JPG 圖片下載回報。
